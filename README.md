# EmprendeCopilot

Landing responsive en español, realizada con HTML, CSS y JavaScript sin dependencias. Abre `dist/index.html` o sirve `dist` con un servidor estático.

Incluye las nueve secciones solicitadas, menú móvil, navegación y selección de planes con registro de demostración local. No incorpora autenticación, cobros, integraciones con WhatsApp ni un backend de IA. El testimonio y las cifras del panel están identificados como ejemplos. Las fotografías ilustrativas se cargan desde Unsplash y requieren conexión.

Para modificar el diseño edita `dist/styles.css`, el contenido en `dist/index.html` y las interacciones en `dist/app.js`.
